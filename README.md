# 珊瑚水族与钓具中心 · Coral Aquarium and Tackle Centre

Responsive Chinese business landing page, with supplied company branding, four store photographs, a photo viewer, two embedded Facebook videos, product categories and store directions.

## Hosting

Static HTML, CSS and JavaScript. No build or dependency installation is required. GitHub Pages publishes the `main` branch from the repository root. All application assets use relative paths so they work beneath `/Coral/`.

## Local preview

Run `python -m http.server 4173` from this directory.

## Content

Business copy, logo and store photographs were provided by the owner. Generic freshwater and outdoor fishing images are illustrative Unsplash photos. Facebook videos remain hosted by Facebook. Existing selected source notes and FAQ section are intentionally hidden.

The phone and opening hours should be confirmed with the shop when plans change. No payment, checkout or inventory backend is included.
